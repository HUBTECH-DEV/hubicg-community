Paulo Cesar Benjamin Junior (`@paullobenjamin`) is the sole authorized core
maintainer and repository maintainer. This authority concerns Git repository
administration and does not change authorship or the patrimonial-rights chain.

Halini (`@halinibenjamin-pm`) is not appointed as a HubICG project maintainer.

retains inherited GitHub administration. Paulo explicitly directed on
2026-08-07 that this permission must not be changed. The inherited permission
is an approved access exception, not a project-governance appointment.

The gate closes only when:

1. `@paullobenjamin` retains repository administration;
2. `MAINTAINERS.md`, `GOVERNANCE.md` and `CODEOWNERS` continue to name only
   Paulo;
3. inherited administrators are recorded separately from maintainers;
4. the verified GitHub permission evidence and Paulo's exception decision are
   recorded and
   `.hubicg/gates/p0-maintainers.json` is set to `approved`.
