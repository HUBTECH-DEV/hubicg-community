# Community role promotion

Promotes 19 declarative Portuguese principal roles for public reuse under AGPL-3.0-only. The repository owner authorized this promotion and the related catalog integration on 2026-10-20. Only the definitions proposed in hubicg-agents-catalog PR #1 are included; no runtime, private configuration or history is copied.

The published JSON bytes are the canonical source for subsequent catalog imports. The catalog must record this public repository, the immutable revision, `.hubicg/roles/` paths, Git blob SHA-1 and content SHA-256.
